# DORA ROI of AI-assisted Software Development

## Summary

- Follow-up DORA report (reference 2026.01; page last updated 2026-04-22; covered by InfoQ in May 2026) focused on quantifying return on AI-assisted development investment.
- Introduces a J-curve of value realization: an initial productivity dip caused by team workflow adaptation, code verification overhead, and downstream processes absorbing increased code volume — framed as "the tuition cost of transformation."
- Value model chains seven capabilities into DORA delivery metrics, then into non-financial outcomes (developer and user experience), then into financial results (cost savings, revenue).
- Worked example: a 500-person engineering organization at $176k fully-loaded salary projects ~$11.6M first-year value against $8.4M investment — 39% ROI with roughly 8-month payback.
- Cites Stanford software engineering productivity research: 35-40% AI productivity gains on simple greenfield tasks versus 10% or less on complex legacy code.
- Reframes ROI for the agentic era: value is not developer headcount replaced but systemic toil automated; describes the shift from reactive AI tools to autonomous multi-step agent workflows.
