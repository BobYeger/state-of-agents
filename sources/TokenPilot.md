# TokenPilot

## Summary

- Context-management paper focused on cache efficiency for long-running LLM agents.
- Uses ingestion-aware compaction to stabilize prompt prefixes and lifecycle-aware eviction to reduce cost.
- Integrated into LightMem2, making it relevant to both research and implementation practice.
- Important harness lesson: context policy affects latency and cost, not only answer quality.
