# MESA

## Summary

- Security paper focused on inter-agent communication channels as an attack surface.
- Ranks communication edges by security criticality using graph metrics and dynamic probes, without requiring attack traces.
- Useful because it moves multi-agent security from "monitor everything" to prioritized hardening of vulnerable edges.
- Important for swarm and graph-of-agent architectures where one compromised channel can propagate bad information.
