# Claude Fable 5 and Claude Mythos 5

## Summary

- Launched 2026-06-09. Anthropic describes Fable 5 as a "Mythos-class" model exceeding anything it has previously made generally available, with state-of-the-art results on nearly all tested benchmarks — highest FrontierCode score even at medium effort, SOTA on CursorBench, and the top Hebbia Finance Benchmark score.
- Priced at $10/M input tokens and $50/M output tokens, described as less than half the price of Claude Mythos Preview.
- Anthropic claims the longest autonomous operation of any Claude model: the model "stays focused across millions of tokens in long-running tasks," with performance further improved when given persistent file-based memory — a vendor datapoint tying long-horizon capability to memory-augmented harness design.
- Stripe early-access example: a codebase-wide migration of a 50-million-line Ruby codebase completed in one day, against an estimated two months for a full human team.
- Mythos 5 is the same underlying model with safeguards lifted in some areas, deployed only via Project Glasswing with the US government; Anthropic claims it has the "strongest cybersecurity capabilities of any model in the world."
