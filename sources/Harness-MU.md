# Harness-MU

## Summary

- Multi-user, multi-principal governance harness for LLM agents.
- Core argument: permissions, restrictions, and instruction precedence are deterministic runtime variables that should be enforced by execution hooks, not entrusted to prompt-following alone.
- Important for harness engineering because it treats governance as infrastructure around the loop.
- Strong source for "hooks are not just convenience scripts; they can enforce policy at execution boundaries."
