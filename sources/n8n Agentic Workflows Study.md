# Characterizing Large Language Model Agentic Workflows

## Summary

- Empirical study of more than 6,000 public n8n workflows using LLM agents.
- Finds LLMs embedded inside broader automation structures with control logic, external services, storage, and human review points.
- Reports that explicit reliability mechanisms such as fallback paths, repair loops, failure-specific alerts, and human approval gates remain uncommon.
- Useful evidence that workflow adoption is moving faster than reliability/governance engineering.
