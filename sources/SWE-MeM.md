# SWE-MeM

## Summary

- Training framework for proactive and on-demand memory management in long-horizon software engineering agents.
- Gives agents a flexible memory tool and trains them to decide when, what, and how to compress based on trajectory state, task progress, and remaining context budget.
- Uses Memory-aware GRPO to jointly optimize memory management and issue resolution.
- Relevant because coding-agent memory becomes a learned policy inside the harness rather than a fixed summarization recipe.
