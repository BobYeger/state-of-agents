# Factory Droid 1.0 Frontier Harness

## Contribution

Describes a deployed Agent Factory: agents combine benchmark traces and user friction, propose explicit hypotheses, and test changes across affected model families; engineers review and merge. The improved Droid then runs the next improvement cycle.

Script mode executes JavaScript tool workflows, keeps intermediate results outside model context, and permits concurrent independent calls. This is a concrete harness capability, not evidence that all tool workflows should become scripts.

## Evidence and Limits

Operator measurements accompany product claims. Head-to-head comparisons use three trials; cost/time consider only tasks both harnesses pass in every trial. Some moderation-blocked runs substitute models, and some Devin question stops receive imputed successes. These choices constrain comparisons.

The article exposes a useful cross-model counterexample: always adding line numbers helps some models but increases other models' cost, so the feature becomes optional. Automation generates changes; human merge remains the release boundary.
