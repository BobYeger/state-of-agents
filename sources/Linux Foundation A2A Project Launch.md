# Linux Foundation A2A Project Launch

## Summary

- Announced June 23, 2025 at Open Source Summit North America: Google donated the A2A protocol specification, SDKs, and developer tooling to a new Linux Foundation project.
- Founding members: Google, AWS, Cisco (Outshift), Microsoft, Salesforce, SAP, ServiceNow; over 100 companies supported the protocol at donation time.
- A2A had been launched by Google only about 2.5 months earlier (April 2025); the donation moved it to neutral LF governance for IP management and long-term stewardship.
- Cisco contributed supporting open-source components: Directory, Identity, SLIM Messaging, and Observability frameworks.
- Canonical repository moved to github.com/a2aproject/A2A.
