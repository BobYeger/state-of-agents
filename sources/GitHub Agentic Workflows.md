# GitHub Agentic Workflows is now in public preview

## Summary

- GitHub public preview for natural-language Markdown workflows that compile into GitHub Actions YAML with agent execution.
- Examples include issue triage, CI failure analysis, and docs workflows.
- The security posture is central: read-only by default, sandboxed container execution, integrity filters, Agent Workflow Firewall, safe outputs, and threat detection.
- Useful code-factory source because it moves agent loops into CI/workflow infrastructure rather than ad hoc chat sessions.
