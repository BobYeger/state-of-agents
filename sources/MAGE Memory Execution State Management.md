# Beyond Semantic Organization

## Summary

- Argues that memory for long-horizon agents should manage execution state, not only semantically organize facts.
- Proposes MAGE, a hierarchical state tree with operations such as Grow, Compress, Maintain, and Revise.
- Reported results include higher success rates and lower token use versus baseline memory/context strategies.
- Useful because it sharpens the distinction between "agent memory" and ordinary document retrieval.
