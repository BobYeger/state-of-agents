# GitHub Agent HQ

## Summary

- Agent HQ makes third-party coding agents from Anthropic, OpenAI, Google, Cognition, and xAI available inside GitHub under paid Copilot subscriptions; OpenAI Codex shipped first (Copilot Pro+ in VS Code Insiders).
- Mission control is a unified command center across GitHub, VS Code, mobile, and CLI for assigning multiple agents in parallel, tracking progress, and resolving merge conflicts in one click — GitHub positioning itself as the manager layer over rival vendors' agents.
- Ships branch controls (granular rules for when CI runs on agent-created code) and agent identity and access management that treats agents like team members.
- Developer-facing additions: Plan Mode in VS Code (clarifying questions before implementation), source-controlled AGENTS.md custom agent guardrails, and the MCP Registry surfaced in VS Code (Stripe, Figma, Sentry servers).
- Enterprise layer in public preview: a control plane for agent/model policy and audit, a Copilot metrics dashboard, and org-wide GitHub Code Quality visibility.
