# Code as Agent Harness

## Summary

- 42-author survey that reframes code from a target output to an "operational substrate for agent reasoning, acting, environment modeling, and execution-based verification" — the first large survey to treat the harness as a first-class research object.
- Organizes the field in three layers: harness interface (reasoning, action, environment modeling), harness mechanisms (planning, memory, tool use, feedback-driven control, optimization), and scaling (multi-agent coordination, review, verification).
- Application coverage spans coding assistants, GUI/OS automation, embodied agents, scientific discovery, DevOps, and enterprise workflows.
- Open problems list maps directly onto code-factory design questions: verification with incomplete feedback, regression-free improvement, multi-agent state consistency, and human safety oversight.
- CC BY 4.0 with a companion GitHub repository.
