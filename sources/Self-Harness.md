# Self-Harness

## Summary

- Proposes a self-improvement loop where an LLM-based agent improves the harness it operates through.
- The loop mines weaknesses, proposes harness updates, and validates changes before accepting them.
- Important because it treats the harness as the mutable artifact, not merely the fixed system around the model.
- Direct evidence for the vault thesis that harness engineering is becoming an optimization target.
