# OpenAI Dots

Documents persistent responsibilities across conversations, saved context, self-selected wakeups, cloud execution, and background delegation. It is a product example of a continuing responsibility whose constituent tasks can finish separately.

The documentation reports gradual rollout. The [September 28–October 2 recap](https://learn.chatgpt.com/docs/whats-new/september-28-october-2-2026) provides a dated mention, not a verified exact launch day. No controlled comparison establishes notification usefulness, optimal wake timing, or long-term task reliability.

## Personal-Agent Boundary

The same dot carries relevant context across ChatGPT, Slack, Teams, and calls. Saved notes cover preferences, decisions, and ongoing work. Its cloud computer can work while the user's devices are off; local access is a separate connection. Pausing the main task, stopping delegated tasks, and canceling recurring work are separate controls. These distinguish a continuing assistant from one background job. The reviewed documentation does not identify algorithm papers as implementation ancestry.
