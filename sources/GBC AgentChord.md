# GBC

## Summary

- Optimization method that models a multi-agent system as a computational graph and assigns token-level influence weights between agents.
- Uses attribution to identify error sources and target prompt optimization.
- Useful because it treats coordination failure as a credit-assignment problem rather than a vague "agents disagreed" phenomenon.
- Secondary source for the multi-agent design map; not as central as workflow/runtime papers, but good for optimization and evaluation.
