# LLM Agents Are Latent Context Managers

## Summary

- Introduces VISTA, a training-free interface that exposes working-memory blocks, token usage, recency, access history, and full-fidelity archive/recovery tools to the agent.
- Core idea: frontier models may already have latent context-management ability, but need visible internal state to make keep/drop decisions.
- Important for harness engineering because it treats context state visibility as a UI/API design problem for the agent itself.
- Useful counterpoint to learned compression policies such as [[sources/SWE-MeM]].
