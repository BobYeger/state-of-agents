# GitHub Agent HQ Claude and Codex

## Summary

- 2026-02-04: Anthropic Claude and OpenAI Codex became runnable as coding agents inside GitHub (public preview) for Copilot Pro+ and Enterprise; extended to Business and Pro tiers 2026-02-26 — the concrete GA moment of the "platform orchestrates rival vendors' agents" pattern.
- Agent sessions start from github.com, GitHub Mobile, and VS Code — from issues, PRs, the repo Agents tab, or the VS Code agent-sessions view; agents run asynchronously and produce reviewable artifacts (comments, drafts, proposed changes).
- Billing: each coding-agent session consumes one premium request under the existing Copilot subscription — no separate Anthropic or OpenAI accounts required.
- Mission control gives enterprise admins agent/model allowlists, access policies, security controls, and audit logging across the org.
- Google, Cognition, and xAI agent integrations were announced as underway, making Agent HQ a multi-vendor orchestration control plane rather than a Copilot feature.
