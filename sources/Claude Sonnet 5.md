# Claude Sonnet 5

## Summary

- Launched 2026-06-30 as Anthropic's "most agentic Sonnet," with substantial gains over Sonnet 4.6 in reasoning, tool use, coding, and knowledge work; Anthropic says it nearly matches Opus 4.8 at lower cost, with adjustable effort levels.
- Introductory pricing of $2/M input and $10/M output tokens through 2026-08-31, then $3/$15 — positioned explicitly as a cheaper way to run agents.
- Anthropic states it runs autonomously with browser and terminal tools at a level that months earlier required larger, more expensive models — the capability tier relevant to orchestrator-plus-cheap-worker cost models.
- Became the default model for Free and Pro plans; API id `claude-sonnet-5`; available in Claude Code and Claude Platform; GitHub added it to Copilot at launch.
