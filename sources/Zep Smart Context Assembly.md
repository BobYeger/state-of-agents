# Smart Context Assembly

## Summary

- Zep product update for building a smaller, query-adaptive context block from multiple context types.
- Ranks candidates across facts, entities, episodes, observations, summaries, and user summary under a fixed character budget.
- Useful practical example of progressive context assembly: context shape adapts to the query rather than using a fixed per-type quota.
