# AlphaEvolve

## Summary

- Evolutionary coding agent for scientific and algorithmic discovery, combining LLM-generated code edits with automated evaluators and a program database.
- Important because it demonstrates self-improving code loops in production and scientific settings where evaluation is objective and automatable.
- Reported applications include data-center scheduling, TPU hardware design, AI-training kernels, FlashAttention optimization, matrix multiplication, and open mathematical problems.
- Distinction: AlphaEvolve improves algorithms/programs, not necessarily the agent scaffold itself; it is still central to the self-improving-code loop family.
