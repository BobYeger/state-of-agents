# Memora

## Summary

- Microsoft Research memory system for long-horizon agents that decouples stored content from retrieval abstraction.
- Uses richer memory content plus lightweight abstractions and cue anchors to balance specificity and abstraction.
- Reported as ICML 2026 work and positioned as outperforming Mem0, RAG, and full-context inference while using far fewer context tokens.
- Useful product/research source for the idea that durable memory needs its own representation layer, not just larger context windows.
