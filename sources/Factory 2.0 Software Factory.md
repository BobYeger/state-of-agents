# Factory 2.0: From coding agents to software factories

## Summary

- Factory frames the next step after individual coding-agent productivity as an interconnected, agent-native, end-to-end software factory.
- The factory loop begins with external signals, turns them into planned changes, builds/tests/reviews/secures/ships/monitors those changes, and feeds monitoring back into new signals.
- The proposed factory requirements are model independence, sovereign control over organizational learning, and continual self-improvement across SDLC stages.
- Important product vocabulary: Droids for task execution, skills for bounded procedures, automations for recurring workflows with objective and memory, Droid Computers for persistent execution, and Missions for multi-agent autonomous execution.
- This is useful as a June 2026 vendor anchor for [[concepts/code factories]] and for the claim that harness engineering is becoming organization-level SDLC control design.
