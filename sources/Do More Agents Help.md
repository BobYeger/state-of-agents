# Do More Agents Help?

## Summary

- Controlled evaluation of LLM agent workflows that asks when multi-agent systems actually outperform matched single-agent baselines.
- Reports that fixed multi-agent workflows often trail matched single-agent setups, while runtime-generated workflows can help on harder tasks.
- Important corrective source: "multi-agent" is not automatically better; benefit depends on decomposition, protocol, task structure, and aggregation.
- Strong support for the vault rule that multi-agent systems work when tasks are separable and aggregation is explicit.
