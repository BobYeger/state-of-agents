# Adaptive Auto-Harness

## Summary

- Extends auto-harness optimization from fixed offline benchmarks to open-ended task streams.
- Uses a stateful multi-agent evolver, a harness tree with solve-time routing, and human-steering hooks where history lacks enough signal.
- Important because real deployments see shifting task distributions and growing histories, so a single densely updated harness can become brittle.
- Strong source for distinguishing one-off harness optimization from sustained harness operations.
