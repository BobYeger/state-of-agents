# Three Key Loops for Building Great Software

## Summary

- Andrew Ng frames June 2026 loop engineering as nested product-development loops rather than only a coding-agent primitive.
- The three loops run at different cadences: agentic coding loop in minutes, developer feedback loop in hours, and external feedback loop in days or longer.
- The agentic coding loop covers code generation, testing, and iteration against specs and optional evals.
- The developer feedback loop shifts human work upward from manual QA toward product direction, UI choices, feature selection, spec refinement, and eval design.
- The external feedback loop brings users, alpha tests, production data, and A/B tests back into the developer vision that drives the next spec.
- Important distinction: humans still have a context advantage about users and product setting, so human-in-loop is not just a safety brake; it injects context the agent does not have.
