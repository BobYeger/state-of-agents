# A Cognitive Framework for Delegation to an Assistive User Agent

## Contribution

This CALO-motivated extension of belief–desire–intention architecture separates user-delegated candidate goals from feasible adopted goals and committed plans. Pending tasks can survive temporary infeasibility until circumstances change or they expire.

Commitment deliberation jointly considers accepting new work and revising existing obligations, accounting for deadlines, priorities, execution progress, and switching costs. User advice guides what to pursue and how to execute it; ambiguous tradeoffs can prompt consultation. Persistence therefore requires maintained obligations and revision rules beyond a conversation history or recurring timer.

## Evidence Boundary

This is a proposed architecture with a worked example. Operationalization in SPARK for CALO was in progress, not an evaluated autonomous deployment. Broad proactive discovery of user goals and multiagent coordination remained future work. Advice is modeled as a negotiable preference, not a modern security permission boundary. The paper is a conceptual precedent; direct adoption by contemporary products is not documented.
