# MCP Specification 2026-07-28 Release Candidate

## Summary

- The release candidate for MCP revision 2026-07-28 froze on May 21, 2026 and entered a 10-week SDK validation window. The final revision subsequently published on July 28, 2026 ([[sources/MCP Specification 2026-07-28]]), so this card is now a historical record rather than the normative protocol source.
- The RC is useful evidence for process: it was the first public specification freeze followed by a fixed SDK-validation interval under MCP's working-group release model. Much of its design subsequently shipped, but only the final specification controls current requirements.
- Companion context: the 2026 MCP Roadmap (blog, March 9, 2026) shifted planning from fixed releases to working-group-driven development, with a contributor ladder and SEP authority delegated to working groups.
