# The Red Queen Godel Machine

## Summary

- Self-improving agent framework where evaluation can evolve across epochs rather than remain fixed forever.
- Organizes search into epochs with fixed within-epoch criteria, then allows the utility/evaluator to change at epoch boundaries.
- Important because it addresses the evaluator bottleneck in recursive self-improvement and autoresearch.
- Treat as promising but higher-risk: evolving evaluators increase power and also increase the burden on governance, auditability, and anti-objective-hacking controls.
