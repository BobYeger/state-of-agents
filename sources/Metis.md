# Metis

## Summary

- Studies text memory and code memory over the same experience set, then proposes a dual-representation memory for self-evolving agents.
- Text memories store execution plans, environment facts, and pitfalls; recurring plans can be crystallized into validated callable tools.
- Important because it connects memory, skills, and tools as different persistence formats for agent experience.
- Useful bridge from [[sources/SkillOpt]] to agent-memory systems.
