# Memory in the Age of AI Agents

## Summary

- Large 47-author survey (v1 2025-12-15, v2 2026-01-13) proposing memory as a first-class primitive of agentic intelligence.
- Three-axis taxonomy: forms (token-level, parametric, latent memory), functions (factual, experiential, working memory), and dynamics (formation, evolution, retrieval).
- Explicitly names multi-agent memory as an emerging research frontier and traces the shift from isolated per-agent memories with message passing to centralized shared structures (global vector stores, blackboards, shared documents).
- Delineates agent memory from LLM memory, RAG, and context engineering to resolve conceptual fragmentation — a boundary the vault's memory notes have tended to blur.
- Compiles a comprehensive summary of memory benchmarks and open-source memory frameworks; companion paper list maintained at github.com/Shichun-Liu/Agent-Memory-Paper-List.
