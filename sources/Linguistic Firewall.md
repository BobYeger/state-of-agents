# Linguistic Firewall

## Summary

- Multi-agent routing security paper that replaces text-description-based routing with active capability testing and non-textual algebraic routing.
- Addresses attacks where malicious agents misrepresent capabilities through descriptions or metadata.
- Useful for the vault's runtime routing thread: routing should be based on observed capability and policy, not self-asserted descriptions alone.
- Pairs with [[sources/MESA]] as part of the June 2026 multi-agent security cluster.
