# Build Cross-Language Multi-Agent Team with Google's Agent Development Kit and A2A

## Summary

- Practical Google ADK/A2A article showing a Python extraction agent and Go compliance validator connected into a coordinated pipeline.
- Shows production multi-agent decomposition around language/runtime boundaries: teams can expose narrow agents/services through A2A without rewriting the implementation.
- Useful for explaining that "multi-agent" can mean distributed services with explicit state transitions and fail-safe human review, not only LLM personas in one prompt.
