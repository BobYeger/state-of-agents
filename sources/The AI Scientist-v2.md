# The AI Scientist-v2

## Summary

- End-to-end autonomous scientific discovery system using agentic tree search to formulate hypotheses, design and execute experiments, analyze data, visualize results, and write manuscripts.
- Important because it is one of the most visible autonomous-research examples and has stronger early citation signal than most 2025 self-improving-code sources in this cluster.
- Removes more human-authored template dependence than the original AI Scientist and uses an experiment-manager agent plus VLM reviewer feedback loop.
- Reported milestone: one fully AI-generated manuscript passed the average human acceptance threshold at an ICLR workshop.
