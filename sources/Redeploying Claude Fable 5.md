# Redeploying Claude Fable 5

## Summary

- First government-ordered takedown-and-restore of a frontier agent model. Timeline: US government imposed export controls on Fable 5 and Mythos 5 on 2026-06-12 and Anthropic suspended access globally; controls were lifted 2026-06-30 and access restored worldwide 2026-07-01.
- Trigger: Amazon researchers jailbroke Fable 5 into producing working exploit code for a software vulnerability. Anthropic's own testing found less capable models could replicate the behavior — the jailbreak surfaced a borderline safeguard case rather than a uniquely dangerous capability.
- Proposes an industry-wide jailbreak severity scoring framework with four criteria: capability gain, breadth, weaponization ease, and discoverability.
- Post-restoration availability: Claude.ai, Claude Code, and Claude Cowork globally; paid plans include Fable 5 at 50% usage limits through July 7, then usage credits; AWS, Google Cloud, and Microsoft Foundry access being restored.
