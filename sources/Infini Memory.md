# Infini Memory

## Summary

- Long-term agent memory system based on maintainable topic documents.
- Observations are staged and later consolidated into topic-structured memory documents.
- Retrieval is agentic: the agent can iteratively call memory tools rather than receive a fixed context dump.
- Useful middle ground between plain markdown memory and database-backed memory systems.
