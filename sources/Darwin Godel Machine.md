# Darwin Godel Machine

## Summary

- Self-improving coding-agent system that iteratively modifies its own code, evaluates modified agents on coding benchmarks, and keeps a growing archive of generated agents.
- Important because it replaces the theoretical Godel Machine's proof requirement with empirical validation and open-ended evolutionary search.
- Reported improvements: SWE-bench from 20.0% to 50.0%, Polyglot from 14.2% to 30.7%.
- The project explicitly documents safety controls and objective-hacking examples, making it a key source for both self-improvement and harness governance.
