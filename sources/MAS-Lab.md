# MAS-Lab

## Summary

- Specification-driven framework for reliable multi-agent systems.
- Separates semantic intent from operational concerns through a specification layer, a stateful MAS operating system layer, and lab overlays for observability/evaluation.
- Important because it frames multi-agent systems as engineered distributed systems, not ad hoc agent scripts.
- Good bridge between harness engineering and multi-agent orchestration.
